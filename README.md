# Lustre Lane — Imitation Jewellery & Bangles Store

A responsive, boutique e-commerce storefront for imitation jewellery and bangles.

## Pages
- `index.html` — Home 1 (Hero showcase, mood categories, bestsellers, celebration edit, testimonials)
- `home2.html` — Home 2 (Editorial layout, curated calendar styles, signature pieces)
- `shop.html` — Complete jewellery catalogue with uniform card actions
- `collections.html` — Curated edits (Bangle Bar, Wedding Guest Edit, Everyday Essentials, etc.)
- `about.html` — Brand story, promises, craftsmanship and values
- `contact.html` — Boutique contact info, interactive Google Map, social media links & enquiry form
- `login.html`, `signup.html`, `forgot-password.html`, `reset-password.html` — Dedicated, distraction-free authentication pages

## Features
- **Brand Identity**: Cohesive brand logo and typography across navbar, footer and auth headers
- **Card CTA Alignment**: Uniform flex alignment for all product and collection cards across all grid breakpoints
- **Interactive Map & Socials**: Google Maps boutique locator and styled social media icons (Instagram, Facebook, Pinterest, WhatsApp, YouTube)
- **Dedicated Auth Experience**: Clean authentication pages without full-site navigation distractions
- **Theme & Direction Support**: Dark / Light theme toggle and RTL / LTR layout toggle with local storage persistence
- **Responsive & Accessible**: Mobile-first responsive layouts with fluid typography and accessible form controls
